# Tipos de classes diferentes

## Classes Personalizadas
Classes comuns que criamos, editamos e tudo mais

## Classes Padrões
Classes já feitas e que importamos para utilizar, como:
- Scanner
- Random
- JOptionPane

## Classes Finais
Classes que podemos utilizar, sem importar, invocando diretamente(ex: STRING xxx = "xxx") ou utilizando o formato classico de classes(ex: STRING xxx = new STRING()). Exemplo disso é a classe STRING

## Classes Estáticas
Classes que não precisamos importar, e estão prontas para nosso uso, como a classe MATH

## Collections
- Array
- List
- ArrayList
- Dictionary
