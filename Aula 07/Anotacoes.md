
# Collections

## Array(vetor)
ex: int numbers[] = new int [10];

## ArrayList(vetor tipo lista)
ex: ArrayList list = new ArrayList<>();
list.add("xyz");
list.add(33);

## List(vetor tipo lista tipada)
ex: List<String> list = new ArrayList<String>();
list.add("Olá");

## LinkedList: é um list que utiliza ponteiros que apontam para o seguimnte, e uqando apagamos um item o ponteiro só muda de direção, utilizando menos processamento em caso de remoções. não usa index

## SortedSet: lista ordenada
